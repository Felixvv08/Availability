Verbind een gratis Firebase database zodat iedereen zijn beschikbaarheid kan invullen en het groepsoverzicht zien.

📋 Hoe maak ik een gratis Firebase database?

Stap 1 — Maak een Firebase project

  1. Ga naar console.firebase.google.com
  2. Klik "Project toevoegen", geef het een naam, schakel Analytics uit

Stap 2 — Realtime Database

  1. Klik links op Build → Realtime Database → Database aanmaken
  2. Kies een locatie, kies "In testmodus starten"

Stap 3 — Beveiligingsregels

  1. Ga naar tabblad Regels, vervang alles door: 
    {"rules":{".read":true,".write":true}}
  2. Klik Publiceren

Stap 4 — URL

  1. Kopieer de URL uit tabblad Data (bijv. https://project-rtdb.firebaseio.com)

👋 Wie ben je?

Selecteer jouw naam of maak een nieuw account aan. Jouw planning is persoonlijk — het groepsoverzicht is voor iedereen.
